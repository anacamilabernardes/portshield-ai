# Contributing

Use public/synthetic material only. Never submit internal PDFs, operational events, topology,
credentials or personal records. New public sources need rights/provenance review and explicit approval.
Discuss taxonomy changes via ADR; update schema, generator, prompt and evaluation together.
Run pytest, standard-library unittest and the publication-content check before submitting a PR.
GPU PRs include exact model/dataset hashes, config, environment freeze, hardware and actual results;
mark unmeasured values null. Do not commit weights, tokens, notebook outputs or institutional logs.
